# Uniqueman Men's Wear

Official website for **Uniqueman Men's Wear** — Exclusive men's clothing outlet in Jhilmil, Delhi.

## Features

- Product catalog with search, filters & sorting
- Pre-booking system for clothes
- Wishlist
- User login / register
- Admin dashboard with full inventory management
- Fully responsive (mobile-friendly)
- Light coffee color theme

## How to View

1. Enable **GitHub Pages**: Go to Settings → Pages → Source: Deploy from a branch → main → / (root) → Save
2. Your site will be live at: `https://shaswatxphantom.github.io/uniqueman-mens-wear/`

Or simply open `index.html` in any browser.
